# CompanyFlow

A responsive company-management dashboard built with React and Vite. Track team members, departments, attendance, leave requests, and tasks in one place.

## Features

- Overview dashboard with team metrics and recent activity
- Employee directory with search and an add-employee form
- Department overview
- Attendance status tracking
- Leave request review (approve or decline)
- Task tracking with status updates
- Responsive layout for desktop and mobile
- Browser local storage persistence — demo data stays in your browser

## Run locally

Requirements: Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

Create a production build with:

```bash
npm run build
npm run preview
```

## Demo data and privacy

This portfolio demo runs entirely in the browser. Changes are saved to local storage on the current browser and device; there is no server, user login, or shared database. Use fictional information in the demo.
